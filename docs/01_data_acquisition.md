# 模块一：数据获取与协变量装配

脚本：根目录 `13_*.R`/`13_*.sh` ~ `22_varpart_3dim.R`（GLC 地表覆盖、ERA5 气象再分析、
台站气象聚合、夜间灯光、社会经济协变量装配）。

## 状态速览

视为**稳定基座**，18 个自变量已定型（见下），除风速外基本不再需要改动。下游模块
（CCM、分类回归）直接消费 `22_varpart_3dim.R` 产出的协变量表。

**最终 18 个自变量**（`22_varpart_3dim.R` 的 `CORE`）分三维度：
- 土地利用：不透水面、草地、水体 + 叶型×物候 5 类森林
- 气候环境：气温、湿度、云量、降水、辐射均值、辐射年际 SD、海拔
- 社会经济：夜间灯光 log、绿地投资 log、城镇化率

## 更新日志

### 2026-08-30（之前若干轮对话合并整理）
- GLC_FCS30D 地表覆盖：从 zip64 中央目录解析 + HTTP range 按需取瓦片，46 个瓦片，
  输出 1000m 缓冲区内 29 类占比（`glc_cell_<年>.csv` / `glc_station_<年>.csv`）。
  坑：瓦片命名 `Exxx` 是西边界、`Nyy` 是**北**边界（曾按南边界理解，白下 10 个瓦片
  约 4GB）；curl 不能加 `--retry`（断流重试会重复输出已传字节，导致 zlib
  "invalid block type"），改为自己重试 + 精确长度校验。
- ERA5-Land 下行短波辐射：ssrd 取 23:00 UTC 时次除以 86400 得 W/m²；ERA5 按 UTC
  累积、中国 UTC+8，对 8 天合成影响约 4%，可接受；近海站（如 54623）整站落在海洋
  掩膜上，用 25km 半径内陆地像元均值补值。
- 台站气象聚合：只挡 999999 不够，个别站有 250022.6 / 750006.6 这类缺测码混入日均
  的脏值，改用物理量程过滤。
- 夜间灯光交叉验证：自采 GLC/NTL 与用户已有的 mvnl 一致（CCC 0.983，
  mine = 0.355 + 0.970 × yours）。并确认此前的 WS 协变量文件**不是** GLC_FCS30D
  （176 站被标为永久冰雪、98 站在 35°N 以南），故弃用。
- 城镇化率原打算用统计年鉴口径，但 2000–2022 全空、2023 仅 297 条，改用非农/户籍
  人口比例代理（288 城）。
- 建筑高度/建筑面积/路网密度覆盖率仅 75.1%，补跑过 21 变量版，三者在分类模块的
  两组回归中均不显著，最终未纳入 CORE 18 变量。
